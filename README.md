# İlkin xəbər — новости Азербайджана

Статический сайт-агрегатор: собирает RSS-ленты азербайджанских СМИ на русском языке и показывает
**только заголовок, короткий анонс (до 220 символов), картинку из ленты, источник и время (МСК)**.
Каждая карточка ведёт на оригинальную статью на сайте источника — полные тексты не копируются.

## Структура
```
build.py            # сборщик: RSS -> site/
templates/index.html# HTML-шаблон
assets/             # style.css, app.js (поиск/фильтры на клиенте), favicon.svg
site/               # ГОТОВЫЙ САЙТ (именно эту папку публикуем)
  index.html  news.json  assets/
screenshot.py       # скриншоты (нужен запущенный сервер на :8080)
```

## Обновить новости
```bash
cd /workspace/az-news
python3 -m venv .venv && .venv/bin/pip install feedparser playwright   # один раз
.venv/bin/python build.py        # перекачивает ленты и пересобирает site/
```
Скрипт печатает, сколько новостей пришло из каждой ленты (OK/FAIL). Неработающая лента просто пропускается.

Автообновление каждые 30 минут (cron):
```
*/30 * * * * cd /workspace/az-news && .venv/bin/python build.py >> build.log 2>&1
```

## Локальный просмотр
```bash
cd site && python3 -m http.server 8080    # http://localhost:8080
```
(Данные встроены прямо в index.html, поэтому страницу можно открыть и как файл.)

## Источники и настройки
Список лент — `FEEDS` в `build.py`; лимит на источник — `PER_SOURCE`; длина анонса — `EXCERPT_LEN`;
рубрики — `CATEGORIES` (регулярки по тегам ленты/заголовку). Название сайта — `SITE_NAME`.

Поиск, фильтр по источнику и рубрикам работают в браузере; состояние сохраняется в URL
(`?q=Баку&src=Report.az&cat=Экономика`).

## Публикация (бесплатно)
- **GitHub Pages** + GitHub Actions по расписанию (cron) — сайт сам обновляется без компьютера.
- **Netlify** / **Cloudflare Pages** — загрузить папку `site/` (drag & drop) или подключить репозиторий
  с командой сборки `pip install feedparser && python build.py` и папкой публикации `site`.
